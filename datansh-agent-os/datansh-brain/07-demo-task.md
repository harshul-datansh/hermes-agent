# Demo Task

We want Datansh internal agents that can work on our own software projects.

For this POC, design an agent workflow that can inspect a repository, understand a feature request, create an implementation plan, review the plan, identify tests, and save useful project learnings to a local Datansh brain.

## Acceptance Criteria

- A Master Orchestrator routes the task to specialist roles.
- PM, Researcher, Developer, Reviewer/QA, and Memory Curator outputs are saved separately.
- A final master report combines the outputs into a practical one-day plan and next-week roadmap.
- Structured events are written for visual monitoring.
- Brain memory files receive dated updates.
- No secrets are written to tracked files or event logs.
